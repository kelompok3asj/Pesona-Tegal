# Pesona Tegal

Website informasi pariwisata Kabupaten Tegal, Jawa Tengah. Website ini memperkenalkan destinasi alam, desa, pantai, edukasi, dan budaya, sekaligus mengajak pengunjung berwisata dengan bijak.

Dibuat oleh **Kelompok 3 XII TJKT 6** sebagai Proyek Pembelajaran Informatika.

## Destinasi

| Destinasi | Kategori |
| --- | --- |
| Desa Kedungbanteng | Desa dan budaya |
| Wisata Air Panas Guci | Wisata alam |
| Waduk Cacaban | Wisata air |
| Pantai Purwahamba Indah | Wisata pantai |
| Wisata Kesehatan Jamu Kalibakung | Wisata edukasi |
| Rumah Wayang | Wisata budaya |

## Fitur

- Halaman tunggal dengan navigasi tetap: Beranda, Tentang, Destinasi, dan Tentang Kami
- Kartu destinasi dengan tautan ke situs resmi atau lokasi di Google Maps
- Tampilan responsif untuk desktop, tablet, dan HP
- Daftar sumber informasi resmi

## Struktur Berkas

```
PesonaTegal/
├── index.html   # Isi dan struktur halaman
├── style.css    # Tampilan dan aturan responsif

```

## Cara Menjalankan

Website ini hanya memakai HTML dan CSS, jadi tidak perlu instalasi. Unduh repositori ini, lalu buka `index.html` di browser. Koneksi internet diperlukan untuk memuat foto.
